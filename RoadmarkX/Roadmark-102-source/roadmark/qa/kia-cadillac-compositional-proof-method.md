# Kia/Cadillac compositional guard proof

This matrix invokes the actual application guard functions. It is exhaustive isolated/compositional guard coverage plus full-payload integration and representative/composite checks, not a claim that every case executes the entire original payload.

## Preserved scope

- The original matrix's mutation list remains intact, including every effective fact field change/deletion, complete-map boundary, explicit dependency, identity, availability, accepted source, expiry and malformed deadline probe
- Every affected own or related editorial consumer remains in the tested record set
- Every clause dependency touching the mutated fact or configuration is retained
- Every deadline and arithmetic operand is retained
- First-source witnesses preserve the complete original clause source list in its original order
- Record model-year dependencies and built-in eligibility/source/date gates remain executable

## Conditional reductions

Only fact/configuration mutations with the original source array, policy and known original or isolated-fact proposal are reduced. Source mutations, policy/expiry mutations, direct proposal mutations and full-payload representative/composite tests execute the complete payload.

For each fact mutation, the harness proves that all other configurations are the same objects, every other top-level field is identical, every omitted fact-map key is present in the same order and every omitted fact remains the original object. It then projects the mutated fact plus all retained dependency witness facts. Expected own/related maps use exactly the same projection. Changes to an omitted key fail the invariant check rather than being silently skipped.

For a whole-configuration mutation, the harness identifies every changed top-level field by exact comparison. It retains each corresponding own/related identity predicate, all affected dependencies and applicable own/related availability predicates. Any changed complete fact map remains complete; this path does not project it.

Every distinct reduction group must produce a baseline Map deeply equal to the affected subset of the full original baseline. Equality includes labels, text, visible conditions, source order, accepted source snapshots, review dates and clause deadlines. There is no text-only or count-only substitute for this check.

## Full-payload controls

The full original payload is used for baseline and exact append integration. It also runs all source and expiry matrices, representative mutations for every configuration and every related edge, all guard categories, and combined source/fact/identity/availability mutations. The preserved original interrupted matrix separately completed all 23,115 explicit dependency mutations before optimization; that partial run is not counted as another complete validation.

See the final validation JSON for actual composition counters, baseline-equivalence groups, executed case counts and full_payload_* categories. All source and application hashes must match at both the start and end of the proof.

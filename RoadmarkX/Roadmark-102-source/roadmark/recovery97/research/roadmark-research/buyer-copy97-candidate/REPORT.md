## Mechanism and boundaries

`buyerDisplayCopy(id, field, original)` returns a replacement only when **all three strings match exactly**. Otherwise it returns the original text unchanged. Unknown IDs, unknown fields, changed punctuation/case/spacing, added warnings and reordered Market limitations are preserved. It accepts no car, source, snapshot or other mutable data object and imports no data, time, ranking or browser module.

The helper is called only at these existing JSX text positions:

- Discovery configuration scope
- Exact-trim detail configuration scope
- Market `evidenceNote`
- Market indexed `limitations[i]`

The same components serve app and portable routes. The transport/projection functions and exported/packed evidence remain raw. Existing HTML structure, progressive rendering, prefetch=false choices, links and clock-readiness logic are unchanged. **The initial freshness placeholder is explicitly excluded.**

Four relevant configuration identities appear in hash-keyed buyer-summary snapshots. None is rewritten. The active scope, frozen readiness scope, snapshot scope and original research copy remain byte-for-byte intact in their input files.

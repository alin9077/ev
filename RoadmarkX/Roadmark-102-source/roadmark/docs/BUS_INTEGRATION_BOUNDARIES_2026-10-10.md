# Roadmark bus integration boundaries

Checked 10 October 2026. Read-only preparation; no application edits or new external research.

## Recommendation

Admit **seven bounded current-listed sales configurations** from the eight proposed base evidence records, with all technical holds preserved. **None establishes a confirmed open-order exact build or a uniquely identified NEW stock unit.** Keep **Citirider FBC6120BRS8** as technical audit/search evidence under the current Citirider family until a commercial source binds it to the sold configuration.

The optional **Fleetmaster EV Mining Coach** is one current-listed named Classmaster derivative. Adding it yields eight proposed detail rows across seven admitted base families, not eight newly discovered families or an exhaustive trim set. Existing market-family records must be reconciled, not counted twice.

Mini is a deliberately narrow admission: only its current February-2025 sales-sheet standard-layout identity. It is not a resolved powertrain/homologated passenger-capacity configuration. If the UI cannot make those boundaries visible, retain it as family audit/search rather than weakening the conditions.

## Admission test

A matched current Australian commercial page and dedicated sales sheet can support a bounded listed layout even when some specifications are unknown or disputed. Missing fields are not by themselves proof that the vehicle is unavailable. A linked aftersales/manual technical code with no matched commercial build cannot be promoted merely because its individual technical facts are well sourced. The evidence-package validation pass is provenance/consistency validation, not sales availability or exact-build validation.

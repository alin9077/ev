- Search features, expand categories, filter differences using evidence/condition semantics.

- Media gate rejects missing provenance, denied placement, expiry and wrong build.
- Local shortlist is opt-in; shared URL wins; clipboard failure exposes ordinary link fallback.
- Print includes all vehicles, dated limitations and evidence references.
- Test phone viewport CTA, reflow, dialog semantics and focus with Chromium, WebKit and Firefox.
- Capture 320, 375, 390, 430, 768, 1024 and 1440 px screenshots; inspect representative results.
- Check production build, typecheck, lint, structural validation and domain tests.
- Record laboratory performance separately from real-user Web Vitals and manual real-device testing.
